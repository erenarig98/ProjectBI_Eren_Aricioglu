# InsightBoard

Vite + React + SCSS ile hazırlanmış basit iş zekâsı ve dashboard tasarlama uygulaması.

## Çalıştırma

```bash
npm install
npm run dev
```

Uygulama CSV, XLS ve XLSX dosyalarının ilk satırındaki alan adlarını okuyup grafik oluşturucu paneline ekler. Alanları sürükleyerek görselleştirme alanına bırakabilirsiniz.
